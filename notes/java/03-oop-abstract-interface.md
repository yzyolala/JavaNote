# OOP、抽象类与接口

## OOP 四大概念

OOP = Object-Oriented Programming System。

| 概念 | 说明 |
| --- | --- |
| Abstraction 抽象 | 隐藏复杂实现细节，只暴露必要信息。可通过抽象类和接口实现。 |
| Encapsulation 封装 | 将数据和操作数据的方法封装在类中，通过方法访问数据，提高安全性和可维护性。 |
| Inheritance 继承 | 子类通过 `extends` 继承父类属性和方法，并可添加自己的行为。 |
| Polymorphism 多态 | 通过方法重载和方法重写实现。同名方法可以在不同场景表现不同。 |

## 抽象类

- 抽象类是受限制的类，不能直接创建对象。
- 如果一个类包含至少一个抽象方法，该类应声明为抽象类。
- 子类使用 `extends` 继承抽象类。
- 抽象类可以包含抽象方法、非抽象方法、属性和构造函数。

## 抽象方法

- 只有声明，没有方法体的方法称为抽象方法。
- 抽象方法只能出现在抽象类中。
- 子类负责实现抽象方法。

示例理解：`Vehicle` 可以是抽象类，通用逻辑放在 `Vehicle` 中，`Car` 和 `Bike` 各自实现特定行为。

## 接口

- 接口是一种完全抽象的类型。
- 接口中的方法默认是 `public abstract`。
- 接口中的变量默认是 `public static final` 常量。
- 类通过 `implements` 实现接口。
- 一个类可以实现多个接口。

## 抽象类 vs 接口

| 特征 | 抽象类 | 接口 |
| --- | --- | --- |
| 继承/实现 | 一个类只能继承一个抽象类 | 一个类可以实现多个接口 |
| 内容 | 抽象方法、非抽象方法、常量、属性 | 抽象方法、默认方法、静态方法、常量 |
| 构造函数 | 可以有 | 不能有 |
| 访问修饰符 | 可使用 `public`、`protected`、`private` | 成员默认 `public` |
| 关键字 | `abstract class` | `interface` |
| 目的 | 表示抽象概念并提供共享行为/属性 | 定义一组行为，可由多个不相关类实现 |

## 访问修饰符

可访问性顺序：`public` > `protected` > default > `private`。

| 修饰符 | 访问范围 |
| --- | --- |
| `public` | 任何地方 |
| `protected` | 当前包内 + 外部包的子类 |
| default | 当前包内 |
| `private` | 当前类内部 |

注意：类本身的可见性会影响成员可见性。

## final、finally、finalize

### final

`final` 用于变量、方法和类：

- `final` 变量初始化后不能修改。
- `final` 方法不能被子类重写。
- `final` 类不能被继承。

### finally

`finally` 通常与 `try-catch` 搭配，无论是否发生异常都会执行，常用于释放资源，例如关闭文件、数据库连接或网络套接字。

### finalize

`finalize` 是对象被垃圾回收前可能调用的方法。它可能导致不可预测行为，并影响性能，应谨慎使用。

## 方法重载 vs 方法重写

| 特征 | 重载 Overloading | 重写 Overriding |
| --- | --- | --- |
| 定义位置 | 同一个类或子类中 | 子类中 |
| 方法名 | 必须相同 | 必须相同 |
| 参数列表 | 必须不同 | 必须相同 |
| 返回类型 | 可以相同也可以不同 | 通常必须兼容父类方法 |
| 访问修饰符 | 可以不同 | 不能比父类更严格 |
| `static` / `final` / `private` | 可以被重载 | 不能被重写 |

## 为什么 Java 不支持类的多重继承

Java 不允许一个类同时继承多个类，主要原因：

- **名称冲突**：多个父类拥有同名方法或变量时，子类调用会产生歧义。
- **菱形继承问题**：多个父类继承同一个祖先类时，子类无法确定该使用哪条继承路径上的实现。

Java 使用接口支持多实现，避免类多重继承带来的歧义。

## `P p = new C()` vs `C c = new C()`

如果 `C` 是 `P` 的子类：

```java
C c = new C();
P p = new C();
```

- `C c = new C()`：引用类型和对象类型都是 `C`，可以访问 `C` 中定义的方法。
- `P p = new C()`：对象实际是 `C`，但引用类型是 `P`，只能调用 `P` 类型中定义的方法；如果 `C` 重写了父类方法，会执行 `C` 的实现。
